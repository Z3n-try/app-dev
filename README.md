# My Favorite Series: Avatar: The Last Airbender

> A story about balance, friendship, and growing up.

## About the Series
*Avatar: The Last Airbender* is an animated fantasy series created by **Michael Dante DiMartino** and **Bryan Konietzko**. It aired on Nickelodeon from 2005 to 2008 and has **61 episodes**.

## Main Characters
- Aang
- Katara
- Sokka
- Toph
- Zuko
